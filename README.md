# ゲームデザインの基礎 - 講義テキスト

**"Fundamentals of Game Design, Second Edition"**（Ernest Adams 著）を基にした、日本語講義用教材リポジトリです。

## 概要

697ページの原著PDFから、90分 x 15回の大学講義形式に再構成した日本語教材一式を収録しています。

### 何をしているか

1. **原著PDFからのテキスト・画像抽出** - PyMuPDF / pdftotext を用いて全文テキストと107枚の画像を抽出
2. **日本語要約・講義分割** - 全21章+付録を15回の講義に再構成し、要点を簡潔にまとめたMarkdown教材を作成
3. **Keynoteスライド用テキスト生成** - 各スライド約5行のテキストファイルを302枚分生成
4. **概念図の作成** - draw.io形式で6種類の概念図を作成（XML + PNG）
5. **PDF教科書の生成** - pandoc + weasyprint で全講義を結合したA4判PDF教科書を生成

## 使用ツール

- **テキスト抽出**: PyMuPDF (fitz), pdftotext (poppler)
- **PDF生成**: pandoc 3.x + weasyprint
- **概念図**: draw.io (diagrams.net)
- **生成支援**: Claude Code (Anthropic)
